PolyLine Editor — Phase 1: Requirements AnalysisStudent A Submission | Project InitializationThis repository contains the foundation for a browser-based polyline drawing editor built with Next.js, TypeScript, Tailwind CSS, and the HTML5 Canvas API.📋 Phase 1: Functional RequirementsAs the lead for the Requirements Phase, I have defined the following core specifications to ensure the system handles geometric data accurately:FR-1: Vertex & Edge Logic: The system must support real-time vertex placement ($B$), deletion ($D$), and edge-splitting/insertion ($I$).FR-2: Path Closure: A "Close" command ($C$) must connect the $n^{th}$ vertex to the $1^{st}$ vertex, enforcing a minimum of 3 points for a valid polygon.FR-3: Coordinate Mapping: The editor must support a normalized coordinate system for consistent Zoom and Pan across different screen resolutions.FR-4: State Persistence: All drawings must be serializable into a Version 2 JSON schema for Save/Load functionality ($Ctrl+S/O$).🚩 Challenges and Confusions (Required Section)Per the lab instructions, the following hurdles were encountered during Phase 1:Repository Synchronization: I faced a "fatal: repository not found" error during initial setup.
